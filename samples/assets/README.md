# Sample assets

Shared by `physics_playground` and `model_viewer`. Their `CMakeLists.txt` point at this folder,
not at a copy, so editing a shader while a sample runs hot reloads it.

None of these files comes from a third party.

| File | Origin | License |
|---|---|---|
| `models/torus.obj` | Created for this project by `models/torus_generator.py` (run it in that folder to regenerate the file): a torus with 1024 triangles (512 positions, 561 vertices after the uv seam), with normals and uv. | CC0 1.0 (public domain dedication). |
| `meshes/cube.obj`, `meshes/sphere.obj` | Generated by the author with a script when the scene sample was written (step 6); the script was not kept. | No license file exists in the repository yet. |
| `textures/checker.png` | Created by the author for the scene sample (step 6). | No license file exists in the repository yet. |
| `shaders/phong.vert`, `shaders/phong.frag` | Written for this project. | No license file exists in the repository yet. |
